# Bot_1
Это простой telegram-бот на python с использованием telebot. Первый мой проект с некоммерческой организацией. Этот проект опубликован для того, чтобы мои потенциальные клиенты увидели мои навыки в работе с этим софтом.

=== Файловая структура бота ===

📁 kubrik.json
├── Назначение: Словарь номеров групп (кубриков) для пользователей
├── Формат:
│   {
│     "1": [список_id_участников], 
│     "2": [список_id_участников],
│     ...
│     "8": [список_id_участников]
│   }
└── Требования:
    - Ключи: числа от 1 до 8
    - Значения: массивы числовых Telegram ID
    - Пример: {"1": [123456789, 987654321], "2": [192837465]...}

📁 users.json
├── Назначение: Управление правами доступа
├── Структура:
│   {
│     "admin": [список_id_админов],
│     "user": [список_id_пользователей] 
│   }
└── Особенности:
    - Админы имеют полный доступ к функциям бота
    - Пользователи видят только базовые команды
    - ID вводятся через запятую без кавычек
    - Пример: {"admin": [135792468], "user": [246813579, 987654321]}

📁 users.db
├── Назначение: Основное хранилище данных
├── Автоматическая инициализация при:
│   - Первом запуске бота
│   - Отсутствии файла в директории
└── Содержит:
    - Пользователей
    - Услуги
    - Покупки
    - Историю операций

📁 main.py
├── Назначение: Исполняемый код бота
├── Требования:
│   - Python 3.9+
│   - Зависимости: telebot, sqlite3
│   - Запуск: python main.py
└── Важно:
    - Необходимо поменять значение переменной BOT_TOKEN на API токен бота (10 строчка кода).

=== Инструкция по настройке ===
1. Заполните kubrik.json и users.json по шаблону
2. Разместите все файлы в одной директории
3. Установите зависимости: 
   pip install pyTelegramBotAPI sqlite3
4. Измените значение переменной BOT_TOKEN в файле main.py на API токен вашего бота.
5. Запустите бота: python main.py
6. Для применения изменений в .json и .db файлах 
   требуется перезагрузка бота
